## 2. O-RAN/AI-RAN 产品线

### 2.1 Mavenir Cloud RAN
- **定位**：云原生 RAN 解决方案
- **架构**：完全虚拟化 CU/DU，支持 O-RAN 标准
- **硬件**：基于 Intel Xeon + FlexRAN 加速
- **特点**：云原生、弹性扩缩、微服务架构

### 2.2 Mavenir Open RAN
- **接口**：完全支持 O-RAN 前传（7.2x）、E2、A1
- **集成**：与第三方 RIC 和 xApp 生态集成
- **部署**：支持多种部署模式（集中式、分布式）

### 2.3 AI/ML 产品组合
- **Mavenir RIC**：近实时 RIC 平台
- **xApp 生态**：AI 驱动的 xApp 应用
- **网络自优化**：基于 AI 的自动优化
- **能耗优化**：AI 驱动的节能方案

### 2.4 RIC 平台
- **近实时 RIC**：支持 E2 接口，AI/ML 优化
- **xApp 开发框架**：支持第三方 xApp 开发
- **A1 接口**：与 Non-RT RIC 集成
