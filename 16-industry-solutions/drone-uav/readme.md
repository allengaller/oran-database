## 核心主题

- **5G 网联无人机**：3GPP UAS（Rel-16+）、UAS NF、网络切片、BVLOS 超视距作业
- **DJI 生态切入**：DJI Cloud API、Dock 机场边缘节点、生态合作伙伴模式
- **AI-RAN 三大范式**：AI-for-RAN（切换/波束/干扰优化）、AI-on-RAN（边缘视频推理）、AI-with-RAN（GPU 基带算力共享）
- **低空经济**：通感一体、UTM/UOM 监管对接、低空智联网新基建
