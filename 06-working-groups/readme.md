# O-RAN Alliance Working Groups

## Overview

The O-RAN Alliance operates through 11 technical working groups (WG1-WG11), each responsible for specific aspects of the O-RAN specification framework. This directory documents the detailed responsibilities, work scope, and deliverables of each working group.

## Documents

- [Working Group Overview](./wg-overview.md) - Summary of WG1-WG11 responsibilities, focus areas, and inter-WG dependencies
- [Detailed Working Group Responsibilities](./wg-detailed-responsibilities.md) - In-depth analysis of each working group's charter, deliverables, and contribution pathways

## Working Groups Quick Reference

| WG | Focus Area | Key Deliverables |
|---|---|---|
| WG1 | Use Cases & Requirements | Use case definitions, requirement specifications |
| WG2 | Non-RT RIC & A1 | Non-RT RIC architecture, rApp framework, A1 interface |
| WG3 | Near-RT RIC & E2 | E2AP, E2SM specifications, Near-RT RIC architecture |
| WG4 | Open Fronthaul | O-FH control/user/sync planes, O-RU interfaces |
| WG5 | Open Fronthaul Hardware | O-RU hardware specifications, reference designs |
| WG6 | O-Cloud | O-Cloud architecture, AI/ML orchestration |
| WG7 | White Box Hardware | Open hardware specifications, reference designs |
| WG8 | Stack L1-L3 | L1/L2/L3 protocol stack specifications |
| WG9 | Massive MIMO | MIMO fronthaul, beamforming, performance requirements |
| WG10 | OAM | O1 interface, FCAPS, OAM data models |
| WG11 | Security | Security threat model, interface security, AI security |
