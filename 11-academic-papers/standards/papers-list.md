# O-RAN Standards and Compliance Papers

> Representative papers on O-RAN standardization, 3GPP/ETSI integration, conformance, and interoperability. Each entry: title, authors/affiliations, year, venue, and a one-sentence abstract. Unverified items are marked [需核实].

## 1. Understanding O-RAN: Architecture, Interfaces, Algorithms, Security, and Research Challenges

- **Authors**: Michele Polese, Leonardo Bonati, Salvatore D'Oro, Stefano Basagni, Tommaso Melodia
- **Year / Venue**: 2023, IEEE Communications Surveys & Tutorials
- **Summary**: The canonical reference on O-RAN ALLIANCE specifications, including interfaces, working groups, and standards roadmap.

## 2. Empowering the 6G Cellular Architecture with Open RAN

- **Authors**: Michele Polese, Mischa Dohler, Falko Dressler, Melike Erol-Kantarci, Rittwik Jana, Raymond Knopp, Tommaso Melodia et al.
- **Year / Venue**: 2024, IEEE JSAC, vol. 42, no. 2
- **Summary**: Discusses O-RAN standardization trajectory toward 6G and how O-RAN interfaces relate to 3GPP RAN evolution.

## 3. End-to-End O-RAN Security Architecture, Threat Surface, Coverage, and the Case of the Open Fronthaul

- **Authors**: A. S. Abdalla, V. Marojevic [需核实]
- **Year / Venue**: 2024, IEEE Communications Standards Magazine
- **Summary**: Examines O-RAN security requirements defined by the O-RAN Security Focus Group (WG11) and their coverage.

## 4. Open RAN Security: Challenges and Opportunities

- **Authors**: Madhusanka Liyanage, An Braeken, Shahriar Shahabuddin, Pasika Ranaweera
- **Year / Venue**: 2023, Journal of Network and Computer Applications
- **Summary**: Reviews security requirements from the O-RAN Security Focus Group and compares them with 3GPP security standards.

## 5. O-RAN Alliance Specifications — O-RAN Architecture Description (O-RAN.WG1.OAD)

- **Authors**: O-RAN Alliance WG1
- **Year / Venue**: O-RAN Alliance Technical Specification, continuously updated (v09+, 2024)
- **Summary**: Normative O-RAN reference architecture and interface specifications, aligned with 3GPP RAN releases.

## 6. ORANSlice: An Open-Source 5G Network Slicing Platform for O-RAN

- **Authors**: H. Cheng, S. D'Oro, R. Gangula, et al.
- **Year / Venue**: 2024, ACM MobiCom'24 Workshop on Open and AI RAN
- **Summary**: Implements E2SM-CCC-based control for RAN slicing, demonstrating how O-RAN standards enable standardized service-model-based control.

## 7. OpenRAN Gym: AI/ML Development, Data Collection, and Testing for O-RAN on PAWR Platforms

- **Authors**: Leonardo Bonati, Michele Polese, Salvatore D'Oro, Stefano Basagni, Tommaso Melodia
- **Year / Venue**: 2023, Computer Networks, vol. 220
- **Summary**: O-RAN-compliant experimental toolbox that validates conformance to E2/A1 service models and real RIC interoperability.

## 8. Colosseum: The Open RAN Digital Twin

- **Authors**: Michele Polese, Salvatore D'Oro, Leonardo Bonati, Tommaso Melodia et al.
- **Year / Venue**: 2024, IEEE Communications Magazine
- **Summary**: Colosseum supports O-RAN conformance testing and interoperability validation at scale using its digital twin capability.

## 9. O(ORAN)Analysis: Systematic Testing Framework for Open RAN Implementations

- **Authors**: T. Wang, S. M. Rashil, A. Raphs, G. Tan, S. R. Hussain [作者姓名需核实]
- **Year / Venue**: 2024, USENIX Security Symposium [需核实]
- **Summary**: Proposes systematic testing for open RAN implementations, identifying non-compliance with O-RAN specifications.

## 10. Evaluating the Security of Open Radio Access Networks

- **Authors**: D. Mimran, R. Bino, Y. Kfir, E. Klevansky, O. Brodt, H. Lehmann, Y. Elovici, A. Shabtai [需核实]
- **Year / Venue**: 2022, [需核实]
- **Summary**: Evaluates security of open RAN deployments against O-RAN security requirements, identifying gaps in standard coverage.
