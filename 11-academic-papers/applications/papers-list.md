# O-RAN Application Papers

> Representative papers exploring O-RAN applications and use cases across domains. Each entry: title, authors/affiliations, year, venue, and one-sentence abstract. Unverified items are marked [需核实].

## 1. ORANSlice: An Open-Source 5G Network Slicing Platform for O-RAN

- **Authors**: H. Cheng, S. D'Oro, R. Gangula, S. Velumani, D. Villa, L. Bonati, M. Polese, T. Melodia, et al.
- **Year / Venue**: 2024, ACM MobiCom'24 Workshop on Open and AI RAN
- **Summary**: Open-source end-to-end 5G network slicing platform on O-RAN, demonstrating E2SM-CCC-based slicing control on real testbeds (Arena, X5G).

## 2. Intelligent Closed-loop RAN Control with xApps in OpenRAN Gym

- **Authors**: Leonardo Bonati, Michele Polese, Salvatore D'Oro, Stefano Basagni, Tommaso Melodia
- **Year / Venue**: 2023, Computer Networks (OpenRAN Gym) / 2022, European Wireless
- **Summary**: Applies closed-loop RAN control via xApps on real O-RAN infrastructure, showing how O-RAN enables intelligent control applications.

## 3. Programmable and Customized Intelligence for Traffic Steering in 5G Networks Using Open RAN Architectures

- **Authors**: A. Lacava, M. Polese, R. Sivaraj, T. Zugno, F. Cuomo, T. Melodia
- **Year / Venue**: 2023/2024, IEEE Transactions on Mobile Computing [需核实卷期]
- **Summary**: Applies O-RAN architecture to intelligent traffic steering, a key application of O-RAN programmability in real 5G networks.

## 4. OpenRAN Gym: AI/ML Development, Data Collection, and Testing for O-RAN on PAWR Platforms

- **Authors**: Leonardo Bonati, Michele Polese, Salvatore D'Oro, Stefano Basagni, Tommaso Melodia
- **Year / Venue**: 2023, Computer Networks, vol. 220
- **Summary**: Enables application development (traffic steering, slicing, energy saving) on O-RAN-compliant infrastructure.

## 7. A Comparative Analysis of Deep Reinforcement Learning-based xApps in O-RAN

- **Authors**: Maria Tsampazi, Salvatore D'Oro, Michele Polese, Leonardo Bonati, et al.

- **Summary**: Evaluates DRL xApps for application-driven RAN optimization tasks (e.g., traffic steering, scheduling).

## 8. Towards Continuous Latency Monitoring through Open RAN Interfaces

- **Authors**: Satis Kumar Permal, Yixi Chen, Xin Zhe Khooi, Biqing Qiu, Mun Choon Chan

- **Summary**: Uses O-RAN interfaces for application-layer latency monitoring in deployed Open RAN networks.
