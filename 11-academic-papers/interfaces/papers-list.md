# O-RAN Interface Standards Papers

## 1. Understanding O-RAN: Architecture, Interfaces, Algorithms, Security, and Research Challenges

- **Authors**: Michele Polese, Leonardo Bonati, Salvatore D'Oro, Stefano Basagni, Tommaso Melodia
- **Year / Venue**: 2023, IEEE Communications Surveys & Tutorials, vol. 25, no. 2
- **Summary**: Comprehensive treatment of E2, A1, O1, O2, and open fronthaul interfaces with security analysis.

## 2. End-to-End O-RAN Security Architecture, Threat Surface, Coverage, and the Case of the Open Fronthaul

- **Authors**: A. S. Abdalla, V. Marojevic [需核实]
- **Year / Venue**: 2024, IEEE Communications Standards Magazine
- **Summary**: Analyzes the security of O-RAN interfaces end-to-end, with particular attention to the open fronthaul threat surface.

## 3. Towards Continuous Latency Monitoring through Open RAN Interfaces

- **Authors**: Satis Kumar Permal, Yixi Chen, Xin Zhe Khooi, Biqing Qiu, Mun Choon Chan
- **Year / Venue**: 2024, ACM Workshop on 5G and Beyond Network Measurements, Modeling, and Use Cases
- **Summary**: Demonstrates latency monitoring by reading E2/O1 interface counters from a live Open RAN deployment.
